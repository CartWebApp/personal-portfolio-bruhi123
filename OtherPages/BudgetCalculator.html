Budget Calculator

This is a budget calculator that allows users to input their income and expenses, and then calculates the total budget and displays it on the screen.

Technology Stack

  • Languages: HTML5, CSS3, and JavaScript.
  • Tools: Visual Studio Code for development, Git/GitHub for version control, and Chart.js for JavaScript resources.
  • Deployment: Hosted via Netlify to ensure global accessibility and performance.

Concepts Learned

  • DOM Manipulation: I used ID selectors to connect the HTML to the JavaScript. I also experience the use of core operations to develop my understanding of JavaScript.
  • Semantic Architecture: I barely used any divs in my HTML to improve the readability of my code for future developers in my website.
  • Responsive Design: I used media queries to make a refined product in mobile version (600px)

Challenges & Solutions

  • The Problem: I struggled with my media queries because I needed to convert 1 page into 3 pages, which was something I have never done before
  • The Solution: After I asked for help, Rob kindly helped me how to do it. He taught me you can use a “display: none” to hide sections so to transform it into only one page
  • The Problem: I realize I did not add an API selector in my original draft
  • The Solution: After my web teacher corrected me to fix that section, I rapidly started focusing on that specific issue
  • The Problem: I struggled with my pie chart because of the lack of knowledge to make it
  • The Solution: I used Chart.js to help me build a pie chart and build my skill on JavaScript

Habits of Mind

  • Persistence: I spent a whole hour of class figuring out how to hide and view my media queries for different pages.
  • Communication: I always asked for help when I needed it, I also make sure my developer was doing everything how I wanted.
