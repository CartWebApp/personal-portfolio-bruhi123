My CART Web App Journey

At the beginning of CART, I was pretty confident of my knowledge about coding and how to design websites since I've taken a lot of classes related to computer science. But something that sounded the most scariest to learn was JavaScript. Luckily, I took AP Computer Science A that same year that helped me understand better concepts because they java and JavaScript are very similar. The first project I did really introduced me to coding languages like HTML, CSS, and JavaScript. I saw how everything was connected and I wondered: How am I gonna learn this in a year? It looked very complex but then throughout the months it made me realize it was easier than I thought. When I started learning HTML and CSS it seemed basic, until JavaScript was introduced. I started reading a book called “Eloquent JavaScript”, it gave me a better understanding on how JavaScript works, which helped me abundantly.

After developing projects that helped me building my skills on HTML, CSS, and JavaScript, there was moments were bugs were impossible to fix, but with persistence and hard work all paid of. Even if I asked help from peers, it strengthen my skills on problem-solving and confidence. By the end of the year, all the concepts we learn through the year, we connect them and learned more complex tools that helped us to create more advance and creative websites. I believe this project not just represent what I have learned, but how I had overcome challenges that shaped me into a capable developer which will help me achieve my future goals.
