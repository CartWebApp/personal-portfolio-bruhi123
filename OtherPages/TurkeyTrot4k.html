Budget Calculator

This is a budget calculator that allows users to input their income and expenses, and then calculates the total budget and displays it on the screen.

Technology Stack

  • Languages: HTML5, CSS3, and JavaScript.
  • Tools: Visual Studio Code for development and Git/GitHub for version control.
  • Deployment: Hosted via Netlify to ensure global accessibility and performance.

Concepts Learned

  • DOM Manipulation: I used Ai for the JavaScript because at that time I did not comprehend how to use JavaScript
  • Semantic Architecture: I did not use any divs in my website. I wanted to make it easy to read with semantic selectors.
  • Responsive Design: I learned how to make an easy media by just making it as a column, I think is the easiest and clean way to do it and making it all fit in.

Challenges & Solutions

  • The Problem: Since it was a thanksgiving break assignment, the lack of time was a big issue
  • The Solution: When I had free time I worked on it efficiently
  • The Problem: I did not learn any JavaScript at that time, which was something very important to have in a website
  • The Solution: I asked AI for JavaScript code to make everything look real and clean
  • The Problem: Another problem was that I kind of forgot how to do animations in CSS
  • The Solution: I researched and it was called “@keyframes”. After researching that animation I applied it to my website to make it interactive and appealing

Habits of Mind

  • Persistence: When my CSS animations (using @keyframes) were not firing correctly across different browsers, I spent three days debugging the rendering engine quirks rather than simplifying the design.
  • Communication: I sought feedback from my siblings during Thanksgiving to ensure my website quality met their expectations.
